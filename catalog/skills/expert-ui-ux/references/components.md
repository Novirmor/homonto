# Component and interface criteria

For each important element, specify:

- Purpose, primary action and content hierarchy
- Size, spacing, typography and design-token relationships
- Default, focus, hover, active, disabled and selected states where relevant
- Loading, empty, success, error and recovery behavior
- Responsive layout and content priority
- Semantic structure, accessible name, keyboard operation and focus handling
- Contrast, text resizing, reduced motion and touch-target considerations
- Acceptance checks and evidence still needed

Review findings should identify the observed element, evidence, user impact and
smallest useful correction. Distinguish a measured defect from a stylistic
preference. Never label a page WCAG-conformant based only on appearance or one
automated check.
