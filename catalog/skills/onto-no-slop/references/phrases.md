# Phrase editing

Remove words only when their removal preserves meaning.

| Draft | Clearer wording |
|---|---|
| It is important to note that the request times out after 30 seconds. | The request times out after 30 seconds. |
| This very robust solution seamlessly handles failures. | The worker retries a failed read twice. (Only if observed.) |
| In order to run the tests | To run the tests |

Keep qualifiers such as “usually,” “at most,” “locally,” and “asynchronously”
when they limit the claim. Do not turn “most requests” into “requests,” or
“may fail” into “fails.” Technical terminology is appropriate when precise;
avoid jargon that merely substitutes for an explanation.
