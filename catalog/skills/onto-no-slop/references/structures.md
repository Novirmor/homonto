# Structure editing

- Lead with the outcome, then the evidence or explanation needed to understand it.
- Use headings for distinct questions and lists for steps or independent items.
  A three-item list is fine when there are three useful items.
- Name people when responsibility matters; name components when describing
  behavior. “The cache expires after 60 seconds” is a complete explanation.
- Use passive voice when the affected object is the useful subject: “The token
  is redacted before logging.” Name the actor when ambiguity would matter.
- Keep contrasts that distinguish real contracts. Remove theatrical reversals
  that add no information.
- Choose punctuation and sentence length for readability, not a mechanical ban.
  Preserve required template structure and exact evidence.
